Account & Alerts

Log in

Every node owner has an account: the user id is your callsign. A new account has no password, so ask an admin to set one; then you can change it here and set up your alerts.

My alerts

Alerts go to every destination you fill in. ntfy: install the ntfy app and subscribe to the same topic (pick one nobody would guess).

Services that alert me

Services on your nodes alert you by default. Turn one off here, or ask for alerts from any other service on its node page (Services table).

Password
